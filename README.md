# 🍎 Apple Clone Website

A responsive front-end clone of Apple's official homepage built as a **group collaboration project** using **HTML, CSS, and Git/GitHub**. The project recreates the layout and design of Apple's landing page while practicing collaborative development with Git branches and Pull Requests.

---

## 📌 Project Overview

The Apple Clone project is designed to help students practice:

* Building a responsive website using HTML, and CSS.
* Working collaboratively with Git and GitHub.
* Managing branches, commits, Pull Requests, and code reviews.

---

## 🚀 Features

* Responsive Apple-style homepage.
* Navigation header.
* Hero banners for Apple products.
* Product showcase sections.
* Apple-inspired layout and styling.

## 🌿 Git Workflow

1. Clone the repository.
2. Create a new branch for your assigned task.
3. Make changes and commit frequently.
4. Pull the latest changes from `main`.
5. Push your branch to GitHub.
6. Open a Pull Request for review.
7. After approval, merge into `main`.

Example commands:

```bash
git clone https://github.com/SemhalH/appleClone.git
cd appleClone

git checkout -b header

git add .
git commit -m "Complete header navigation"

git pull origin main
git push -u origin header
```
